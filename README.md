# 📚 Biblioteca Digital Acessível

Este projeto é uma plataforma fictícia de acervo digital desenvolvida com foco em **Acessibilidade Web (WCAG)**, simplicidade e facilidade de navegação.

## 📌 Boas Práticas de Acessibilidade Aplicadas
1. **Hierarquia de Títulos**: Utilização correta de `<h1>`, `<h2>` e `<h3>`.
2. **Textos alternativos em imagens**: Atributos `alt` informativos em todas as capas de livros.
3. **Alto contraste**: Combinação de cores que facilita a leitura de pessoas com baixa visão.
4. **Navegação por Teclado**: Links e botões com foco visível e atalho de "Pular para o conteúdo".
5. **Layout Responsivo**: Adaptação para celulares e computadores via `Flexbox`, `CSS Grid` e `@media`.
6. **Interface limpa**: Sem animações excessivas que possam causar desconforto visual.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
